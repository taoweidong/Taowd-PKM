JeeSite 平台介绍

Platform is introduced

##### ![](assets/images/icon_1_09.png)

#### 行业标杆

十年技术沉淀，适应全行业全领域，擅长企业、政务、医疗、金融二次开发； 设计思想成为[行业标杆](docs/feature/)； 核心小而精，插件丰富可快速伸缩；门槛低上手快，技术先进、安全稳定、[注重代码规范](docs/standard/)。

##### ![](assets/images/icon_1_12.png)

#### 稳定架构

基于 Spring Boot + MyBatis + Shiro + J2Cache / Redis + Beetl 等 [稳定架构](docs/technology/)； 前端 Vue3 or Bootstrap，扁平化响应式设计；支持 Spring Cloud 套件， 可快速开发[分布式、微服务](docs/springcloud/)架构系统。

##### ![](assets/images/icon_1_15.png)

#### 安全可靠

前后台双重验证，数据编码传输，密码加密存储， [密码安全策略](docs/feature/#2安全方面)； 按钮级功能权限，多样化 [数据权限](docs/service-datascope/#数据权限调用) 控制（权限行级、列级权限、自定义权限）；从根本上避免 SQL 注入、XSS、CSRF 等常见攻击。

##### ![](assets/images/icon_1_18.png)

#### 快速开发

强大的 [在线代码生成](docs/code-gen/) 工具， 快速生成单表、一对多、树结构等功能，编译即可运行，自定义业务通用生成模版； [完备内置功能](docs/function/)； 提供多样化 [丰富组件库](docs/views-beetl/)，复用性强，快速开发出优秀产品。

AI 人工智能 + RAG 技术

Artificial Intelligence & RAG Technology

基于 Spring AI 和 JeeSite CMS，结合 RAG 技术和 AI 算法，打造企业级知识管理和智能对话平台。支持云端和本地大模型，集成多种向量数据库。

#### AI 智能助手

深度融合 AI 大模型，支持 OpenAI、DeepSeek、通义千问、Ollama 等接入；智能问答、内容生成、代码编写；

#### RAG 知识库

检索增强生成，自动从企业文档检索信息融入回答；支持 Chroma、PGVector、Milvus 等向量库；

#### Tool 工具调用

支持 Tool Calling 及 MCP 协议；AI 调用 Java 业务逻辑，深度融合交互；结构化输出 JSON、Java 对象；

#### 安全与多模型

支持 Ollama、DeepSeek 本地部署，数据不出内网；亦可按需切换云端模型，灵活安全两不误； [了解详情 >](https://jeesite.com/docs/ai-cms/)
