## 最简单的方式：[BootstrapCDN](http://www.bootstrapcdn.com/#fontawesome_tab) （由[MaxCDN](http://maxcdn.com)提供）

一句话将Font Awesome加入您的网页中。您完全不用下载或者安装任何东西！

  1. 将以下代码粘贴到网页HTML代码的 `<head>` 部分.

         <link href="//netdna.bootstrapcdn.com/font-awesome/4.7.0/css/font-awesome.min.css" rel="stylesheet">


__当新版本发布时，BootstrapCDN需要一点时间来同步到最新版本。稍安勿躁 :)

  2. 参考示例，然后开始使用Font Awesome吧!

## 简单方式之一：使用默认CSS

如果您使用了默认的[Bootstrap](https://bootstrap.dashgame.com) CSS样式，那么你可以使用这种方式来引入默认的Font Awesome CSS样式。

  1. 复制整个 `font-awesome` 文件夹到您的项目中。
  2. 在HTML的 `<head>` 中引用font-awesome.min.css。

         <link rel="stylesheet" href="path/to/font-awesome/css/font-awesome.min.css">


  3. 参考示例，然后开始使用Font Awesome吧!

## 简单方式之二：[LESS Ruby Gem](https://github.com/FortAwesome/font-awesome-less)

使用 [官方 Font Awesome LESS Ruby Gem](https://github.com/FortAwesome/font-awesome-less) 可以简单方便的将 Font Awesome LESS 集成到Rails项目中。由 [@supercodepoet](https://twitter.com/supercodepoet/) 维护。

  1. 将下面这行代码加入到应用的Gemfile中：

         gem 'font-awesome-less'


  2. 然后执行：

         $ bundle


  3. 或者自行安装：

         $ gem install font-awesome-less


## 简单方式之三：[SASS Ruby Gem](https://github.com/FortAwesome/font-awesome-sass)

使用 [官方 Font Awesome SASS Ruby Gem](https://github.com/FortAwesome/font-awesome-sass) 可以简单方便的将 Font Awesome SASS 集成到Rails项目中。由 [@supercodepoet](https://twitter.com/supercodepoet/) 维护。

  1. 将下面这行代码加入到应用的Gemfile中：

         gem 'font-awesome-sass'


  2. 然后执行：

         $ bundle


  3. 或者自行安装：

         $ gem install font-awesome-sass


## 进阶方式：自定义 LESS 或 SASS

使用LESS或SASS的方法来自定义 Font Awesome 4.7.0 。

  1. 复制 `font-awesome/` 目录到您的项目中。
  2. 打开 `font-awesome/less/variables.less` 文件或 `font-awesome/scss/_variables.scss`文件 ，然后修改 `@fa-font-path` 或 `$fa-font-path` 为您的字体目录。

         @fa-font-path:   "../font";


__字体路径是相对于编译的CSS目录。

  3. 如果使用了静态编译器，那么重新编译LESS或SASS文件。如果没有，那么现在应该一切OK了。
  4. 参考示例，然后开始使用Font Awesome吧!

## 需要支持IE7？

如果需要支持IE7，那真的十分抱歉。Font Awesome从4.1.0版本开始不再支持IE7， 但更早的版本仍然支持。您可以查看 [3.2.1 的IE7支持说明](https://fontawesome.com/3.2.1/get-started/#need-ie7)。 然后呢，您可以去找那个非要支持IE7的人算账 :)

您可以将Font Awesome图标使用在几乎任何地方，只需要使用CSS前缀 `fa` ，再加上图标名称。 Font Awesome是为使用内联元素而设计的。我们通常更喜欢使用 `<i>` ，因为它更简洁。 但实际上使用 ` ` 才能更加语义化。


    <i class="fa fa-camera-retro"></i> fa-camera-retro


  * __如果您修改了图标容器的字体大小，图标大小会随之改变。同样的变化也会发生在颜色、阴影等其它任何CSS支持的效果上。

## 组合使用

 ____ fa-flag on fa-circle
 ____ fa-terminal on fa-square

    fa-flag on fa-circle

      <i class="fa fa-terminal fa-stack-1x fa-inverse"></i>

    fa-terminal on fa-square

## 获取帮助

使用Font Awesome的过程中遇到困难了？亦或碰到一个您认为没有正确显示的问题？很抱歉我没有时间来一一回复大家的邮件。 不过以下方式可能对您的情况有所帮助：

  1. 您可以阅读最新版本的怎样起步. 它将用最简单的方式告诉您怎样使用Font Awesome。
  2. 查阅Stack Overflow上 [Font Awesome的相关问题](http://stackoverflow.com/questions/tagged/font-awesome)。其他人或许也有与您相同的问题。
  3. 在Stack Overflow上也找不到问题的答案？ 那么可以[提出一个新问题](http://stackoverflow.com/questions/ask?tags=font-awesome)，然后 [给我发送邮件](mailto:dave@fontawesome.io) ，我或许有时间会看一看。

## 报告Bug

找到Font Awesome的Bug了？那么请直接在GitHub项目中报告就是了。不过请注意以下几点：

  1. 请表现得友好一些。Font Awesome是一个有爱的地方:)
  2. 请先 [搜索](https://github.com/FortAwesome/Font-Awesome/search?type=Issues) 一下，也许这个Bug已经有人提交过了。
  3. 在提交任何问题之前，请先阅读由 [Nicolas Gallagher](https://github.com/necolas/) 编写的 [issue guidelines](https://github.com/necolas/issue-guidelines)
  4. 如果以上几点都OK了，那么请 [提交您的问题](https://github.com/FortAwesome/Font-Awesome/issues/new)。

## 需要新图标

新图标几乎都是在 [Font Awesome GitHub项目](https://github.com/FortAwesome/Font-Awesome/issues)中提出需求的。 如果您也需要，那么这里有一些注意事项需要看看：

  1. 请表现得友好一些。Font Awesome是一个有爱的地方;)
  2. 请先 [搜索](https://github.com/FortAwesome/Font-Awesome/search?type=Issues) 一下，也许您想增加的图标已经有人提交过了。
  3. 请在提出需求时注意以下几点，万分感激：
     * 为 [新需求](https://github.com/FortAwesome/Font-Awesome/issues/new?title=Icon%20Request:%20icon-name) 添加标题 `Icon request: 图标名称`.
     * 举例说明一下您需要在哪些地方用到这个图标，怎么用？
     * 提交一两张单色图片，并确保这张图片能表达您所想要的内容。
  4. 具象化的对象将会诞生出优质的图标，而抽象的概念当然只能用抽象的内容来表现。 举个栗子，一个来表现幸福感的图标远不如一个笑脸图标好制作，也不够直接。 __

  4. After doing everything above, feel free to [submit a pull request](https://github.com/FortAwesome/Font-Awesome/issues/new).
