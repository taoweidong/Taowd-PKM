## 网络精选（高质量博客 · 2026-10-06 增补）

> 以下为 2026-10-06 通过全网检索、验证「仍在线」后下载的本地镜像（落盘于 `wiki-system/sources/curated-web-tools/`）。覆盖开发者在线工具集、API 调试/文档工具、自建 Web 工具、浏览器插件/扩展、效率网站推荐 5 个子方向。

### 摘要

- **在线开发者工具已成完整生态**：浏览器内 IDE（StackBlitz / CodeSandbox / Replit）、前端与格式化工具（Tailwind Play、Can I Use、JSON Crack）、性能与调试工具（Lighthouse、GTmetrix）多数免费，且客户端处理模式更护隐私。
- **API 调试与文档是最高频场景**：Postman 仍是事实标准，Apifox / Insomnia / Hoppscotch / Swagger 构成开源与一体化替代矩阵，OpenAPI 规范成为前后端协作的「契约」。
- **自建（self-hosted）Web 工具用 Docker 即可私有化 SaaS**：Nextcloud（云盘）、Vaultwarden / Bitwarden（密码库）、Gitea（Git）、Uptime Kuma（监控）等，换取数据主权、降本与去锁定。
- **浏览器扩展把浏览器变成开发环境**：Web Developer、Wappalyzer、Lighthouse、JSON Viewer、React Developer Tools 覆盖调试、性能审计、技术栈识别与排版检查。
- **效率网站结合 AI 与自动化成为生产力底座**：项目管理（ClickUp / Notion）、自动化（Zapier / Make）、笔记与知识管理、文件格式转换等，覆盖工作与生活多场景。
