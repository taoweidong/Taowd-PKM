# 中国色 - 中国传统颜色百科与AI配色工具

中国色（zhongguose.com）是中国传统颜色百科与配色工具平台，收录500余种中国传统颜色，提供每种颜色的名称、拼音、RGB值、CMYK值和十六进制(HEX)色值。用户可浏览颜色、创建配色方案、使用AI生成中国风PPT演示文稿和创意海报。

## 核心功能

  * 传统颜色百科：浏览500+种中国传统颜色，每种颜色包含中文名称、拼音、RGB、CMYK、HEX值
  * AI配色工具：基于传统色板生成配色方案，支持PPT配色和可编辑PPT生成
  * AI生成PPT：使用qwen3.8-max模型直接生成SVG幻灯片，产出可编辑PPTX文件
  * AI生成海报：使用万相文生图模型生成中国风创意海报
  * 颜色图集：用户创建和浏览颜色主题图集
  * 共创颜色：社区用户共同创建和命名新颜色
  * 数字藏品：传统颜色NFT数字藏品

## 使用场景

设计师可查找中国传统色配色参考，文化创作者可生成中国风演示文稿和海报，开发者可通过MCP接口集成传统颜色数据，教育工作者可用于传统文化教学。所有颜色数据均基于中科院科技情报编委会名词室出版的色谱标准。
