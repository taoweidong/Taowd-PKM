# 项目-工单管理体系（工程师工作台）

## 摘要
基于 Obsidian + Dataview + Bases 搭建的**个人工程师工作台**：以 Markdown 笔记为唯一数据源，通过 frontmatter 字段 + Dataview 查询 + `.base` 视图，实现"改笔记即改看板"的零中间层项目管理与工单跟踪。

## 详情

### 核心架构
单一入口 `[[50-项目记录/工程师工作台]]` 是仪表盘，聚合：
- 今日聚焦（进行中工单、逾期/临期工单）
- 项目看板（`` ![[项目库.base#全部项目]] ``）
- 工单看板（`` ![[工单库.base#活跃工单]] ``）
- 统计（按状态分组计数）

> [!tip] 单一入口
> 一屏看全局。所有数据来自 `50-项目记录/` 下的 Markdown 笔记，**改笔记即改看板，没有中间层**。

### 项目笔记字段规范（frontmatter）
| 字段 | 取值 |
|------|------|
| `type` | `项目` |
| `status` | 规划中 / 开发中 / 联调中 / 已上线 / 已归档 |
| `stack` | 技术栈列表 |
| `backend_port` / `frontend_port` | 端口 |
| `started` | 起始日期 |
| `health` | 良好 / 有风险 / 阻塞 |
| `repo` | 仓库地址 |

### 工单笔记字段规范（frontmatter）
| 字段 | 取值 |
|------|------|
| `type` | `工单` |
| `project` | wikilink 到所属项目 |
| `status` | 待办 / 进行中 / 待验证 / 已完成 / 已取消 |
| `priority` | P0–P3 |
| `category` | 需求 / Bug / 重构 / 联调 / 部署 |
| `due` / `created` | 截止 / 创建日期 |

### 视图层
- `项目库.base`：项目数据库（看板/卡片/已交付）
- `工单库.base`：工单数据库（活跃/按项目/逾期/本周到期/已完成）
