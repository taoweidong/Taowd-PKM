# Download and provision Elastic

Download [Elasticsearch](/downloads/elasticsearch) to get started with search, observability, and security for free. Deploy on Elastic Cloud (hosted or serverless), run it yourself on-premises, or use our official Kubernetes operator.

#### Copy to try locally in two minutes

For local development and testing, use Docker to install and run Elasticsearch and Kibana on your local machine using start-local.


    curl -fsSL https://elastic.co/start-local | sh
