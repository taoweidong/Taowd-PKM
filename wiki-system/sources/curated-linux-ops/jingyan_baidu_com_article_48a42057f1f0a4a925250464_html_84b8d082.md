jdk是 Java 语言的软件开发工具包，主要用于移动设备、嵌入式设备上的java应用程序。Sun针对Java开发员的产品，后来被Oracle收入旗下。

## [](javascript:;)工具/原料

  * linux(以CentOS为例)

  * jdk

  * 终端

## [](javascript:;)方法/步骤

  1. 1

Oracle官网下载jdk linux安装包，这里以jdk-7u71-linux-x64.tar.gz为例

  2. 2

解压安装包

tar zxvf jdk-7u71-linux-x64.tar.gz

  3. 3

移到相应的位置

mv jdk1.7.0_71 /usr/local/

  4. 4

备份系统环境变量

cp /etc/profile /home/mj/

  5. 5

编辑系统环境变量

vi /etc/profile

输入i

加入内容如下：

export JAVA_HOME=/usr/local/jdk1.7.0_71

export CLASSPATH=.:$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar

export PATH=$JAVA_HOME/bin:$PATH

注意标点符号，JAVA_HOME是刚才mv到路径

  6. 6

加载刚设置的变量

source /etc/profile

  7. 7

测试是否安装成功

输入 java -version 然后会显示jdk的版本信息等

  8. 8

输入javac 会显示javac的命令帮助 这样jdk和环境变量就配置成功了
