## 网络精选（高质量博客 · 2026-10-06 增补）

> 2026-10-06 从全网检索并下载的「仍在线」高质量博客离线镜像，覆盖开源协议、开发者工具链、开源贡献、自托管/Docker 等子方向。本地全文见 `[[wiki-system/sources/curated-opensource-more/]]`。

### 摘要

- **开源协议选型**：MIT / Apache 2.0 属宽松协议（商用友好、限制少），其中 Apache 2.0 额外提供明确的专利授权；GPL / AGPL 属 Copyleft（衍生作品必须开源），AGPL 进一步堵住「SaaS 不发布源码」的漏洞。无许可证 ≠ 开源，反而无人被授权合法使用。
- **自托管 / Docker**：用一份 `docker-compose.yml` 即可拉起整套自托管生态（媒体服务器、文件同步、密码管理、监控、备份）。新手从一台二手迷你主机起步即可，备份（3-2-1）与「不裸奔端口、改用 Tailscale/WireGuard 内网穿透」是安全底线。
- **开源贡献**：从读 README / CONTRIBUTING、认领 `good first issue` 起步，先以文档/错别字/小 bug 为切入点走通 Fork → 分支 → PR 流程；这是提升工程能力与简历含金量最快的路径之一。
- **开发者 CLI 工具**：ripgrep、bat、fzf、tmux 等命令行工具能显著提升日常检索与多任务效率，建议纳入 dotfiles 体系长期沉淀。
