## 今日聚焦

### 进行中

```dataview
TABLE WITHOUT ID
  file.link AS "工单",
  priority AS "优先级",
  project AS "项目",
  due AS "截止"
FROM "50-项目记录/工单"
WHERE type = "工单" AND status = "进行中"
SORT priority ASC
```

### 逾期与临期（7 天内）

```dataview
TABLE WITHOUT ID
  file.link AS "工单",
  priority AS "优先级",
  due AS "截止",
  (date(due) - date(today)).days AS "剩余天数"
FROM "50-项目记录/工单"
WHERE type = "工单" AND status != "已完成" AND status != "已取消" AND due AND due <= date(today) + dur(7 days)
SORT due ASC
```

## 统计

```dataview
TABLE WITHOUT ID
  status AS "工单状态",
  length(rows) AS "数量"
FROM "50-项目记录/工单"
WHERE type = "工单"
GROUP BY status
```

```dataview
TABLE WITHOUT ID
  status AS "项目状态",
  length(rows) AS "数量"
FROM "50-项目记录"
WHERE type = "项目"
GROUP BY status
```

## 字段速查

> [!note] 项目笔记 frontmatter
> `type: 项目` · `status`（规划中/开发中/联调中/已上线/已归档）· `stack` · `backend_port` / `frontend_port` · `started` · `health`（良好/有风险/阻塞）· `repo`

> [!note] 工单笔记 frontmatter
> `type: 工单` · `project`（wikilink 到项目）· `status`（待办/进行中/待验证/已完成/已取消）· `priority`（P0-P3）· `category`（需求/Bug/重构/联调/部署）· `due` · `created`
